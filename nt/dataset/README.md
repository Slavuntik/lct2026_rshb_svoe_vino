# dataset — картинки для нагрузочного прогона

Сюда нужно положить фото, которыми `../loadtest.py` будет бить по API. Сами картинки в git
не хранятся (см. `../.gitignore`), в репозитории есть только этот файл: перед прогоном
наполните папку сами.

- Каталог читается рекурсивно, вложенные папки подходят.
- Берутся файлы `.jpg .jpeg .png .webp .bmp .heic .heif` (регистр расширения не важен),
  остальное пропускается.
- Лучше класть настоящие фото этикеток — тех же размеров и веса, что шлёт мобильный клиент:
  от этого напрямую зависит время приёма и декодирования.
- Потоки делят картинки между собой (поток i шлёт i-ю, i+N-ю, …), поэтому, чтобы замер не
  превращался в проверку кэша сервиса, картинок должно быть заметно больше, чем потоков.

Нужен другой каталог — передайте его раннеру: `../loadtest.py --dataset ~/photos …`.

Если настоящих фото нет, можно сгенерировать заглушки (нужен Pillow). Они годятся только для
замера производительности, не точности:

```bash
python3 ../make_dataset.py --count 40
```
