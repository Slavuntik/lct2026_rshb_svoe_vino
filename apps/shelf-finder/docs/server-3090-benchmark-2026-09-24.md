# Скорость обработки витрины на RTX 3090

На RTX 3090 №2, свободной на момент запуска, проведено девять измерений после одного прогревочного
прохода по каждому из трёх фото. Общая медиана — **6,84 с**, диапазон — **4,96–8,56 с**.
Это вычислительный тест кандидатов, не готовый HTTP-сервис и не оценка точности.

| Фото | Бутылок | Три измерения, с | Медиана, с |
| --- | --- | --- | --- |
| `photo_2026-09-24_17-33-43.jpg` | 44 | 4,96 / 8,34 / 5,75 | 5,75 |
| `photo_2026-09-24_17-33-59.jpg` | 45 | 5,77 / 6,66 / 8,56 | 6,66 |
| `photo_2026-09-24_17-34-31.jpg` | 48 | 7,50 / 6,84 / 8,49 | 7,50 |

## Условия

- YOLO11n ONNX на CPU, пять перекрывающихся областей, NMS.
- SigLIP2 so400m FP16 на GPU: бутылка и этикетка, batch 16, готовые индексы 2103 SKU.
- SIFT/MAGSAC на CPU для десяти кандидатов каждой бутылки; четыре CPU-потока.
- Измеряются декодирование фото, детекция, эмбеддинги, поиск и геометрия.
- Не измеряются сеть, очередь, HTTP-сериализация и финальная калиброванная политика
  принятия названия. Проверенные 14/15 браузерной версии не являются точностью этой цепочки.
- Признаки эталонов кешируются, эмбеддинги запросов вычисляются заново в каждом повторе.
  Прогрев заполнил кеш 343 эталонов. Для новых витрин сервису нужно заранее подготовить
  признаки всего каталога, иначе появятся расходы на заполнение кеша.
- GPU проверена свободной на старте, но эксклюзивный доступ не резервировался.
  CPU сервера общий и нагруженный; разброс существенный.
  Девяти измерений недостаточно для надёжного p95 или оценки конкурентной нагрузки.

Инициализация моделей — 7,30 с. Первый снимок без подготовленного кеша эталонов —
47,34 с (геометрия с подготовкой эталонов — 42,05 с). Поэтому модели и эталоны
следует прогревать до приёма запросов. Пик памяти, выделенной PyTorch, — 2507 MiB;
это не полная память процесса с CUDA-контекстом и сторонними библиотеками.

Практический ориентир: **5–9 секунд вычислений** для такой витрины в одиночном запросе.
При условных 1–3 секундах передачи фото и отсутствии очереди получается **6–12 секунд**
ожидания. Это оценка по замеру, а не гарантия SLA до 10 секунд на телефоне.

## Повторение

Из `apps/shelf-finder`, в окружении WineScan с готовыми индексами:

```bash
CUDA_VISIBLE_DEVICES=2 WINESCAN_ARTIFACTS_DIR=/path/to/artifacts \
  HF_HUB_OFFLINE=1 OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 \
  python scripts/benchmark_server.py \
  --photos /path/to/vitrini --catalog /path/to/catalog.jsonl \
  --images /path/to/strapi/uploads --detector public/models/hybrid/detector.onnx \
  --output artifacts/server-3090-benchmark/results.json \
  --files photo_2026-09-24_17-33-43.jpg photo_2026-09-24_17-33-59.jpg photo_2026-09-24_17-34-31.jpg
```

Выберите свободную GPU. JSON сохраняет замеры стадий, все кандидатные ответы и условия;
ручная разметка в распознавании не используется. Скрипт не меняет браузерный режим.
