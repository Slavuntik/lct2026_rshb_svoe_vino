# Отдельный серверный проект витрин: проверка 24.09.2026

## Что реализовано

`apps/shelf-finder` запускается самостоятельно: пакет `shelf_api`, HTTP на 8086,
свой интерфейс и каталог всех **2103 SKU** организаторов. Основные приложения
Vinchik и WineScan не вызываются. Внешние AI API не нужны.

Детектор YOLO ONNX работает на CPU; ALIKED/VLAD, XFeat и LighterGlue — нативно
на RTX 3090. Эталоны загружаются заранее, кандидаты проверяются пакетами.
Независимая геометрия ALIKED подтверждает результат; при близких первичных оценках
нужен явный перевес того же кандидата по второй модели. Исключений по SKU нет.

В телефоне выполняются подготовка снимка, отправка JPEG с качеством 0,95 и отрисовка.
Камера отправляет один кадр после нажатия кнопки. Только принятые совпадения получают
зелёную заливку и название каталога. Сохранены локальные режимы.

## Реальный интерфейс → HTTP → GPU → разметка

Три исходных снимка 960×1280 из `data/vitrini`, полный каталог, без ручной подстановки
результатов. Сервер заранее прогрет; один запрос за раз. Браузеры запущены на сервере
с viewport iPhone 13, HTTP через localhost, **не на физическом телефоне**.

| Фото | Chromium, весь путь | WebKit, весь путь | Контрольные находки |
| --- | ---: | ---: | ---: |
| `photo_2026-09-24_17-33-43.jpg` | 8,23 с | 5,46 с | 3/4 |
| `photo_2026-09-24_17-33-59.jpg` | 9,32 с | 6,53 с | 8/8 |
| `photo_2026-09-24_17-34-31.jpg` | 6,86 с | 4,63 с | 3/3 |

В обоих браузерах **14/15** известных положительных примеров, без дополнительных
принятых рамок в этих запусках. Пропущена GRAPE DANCE, рамка №3 первого снимка.
Второй Nature Vert на третьем снимке найден. Ошибок JavaScript, сторонних запросов,
загрузок локальных моделей и recognition workers — 0. Разницу времени между
браузерами нельзя считать преимуществом WebKit: это последовательные запуски
на общем сервере, без контролируемого нагрузочного сравнения.

Контрольные примеры взяты из прежнего визуального просмотра Codex, а не независимой
экспертной разметки всех бутылок. 14/15 — полнота на этих положительных примерах,
**не общая accuracy/precision**, не гарантия точного SKU/винтажа. Пороги и алгоритм
дорабатывались на этих снимках; для оценки обобщения нужна отдельная съёмка.

Прямой HTTP-прогон исходных JPEG до браузерной перекодировки дал 7,06 / 9,33 / 7,09 с,
также 14/15, но с другим пропуском и двумя дополнительными непроверенными названиями
Massandra. Поэтому HTTP-результаты исходного файла и результаты загрузки через UI
не взаимозаменяемы. Первый SigLIP/SIFT-бенчмарк — отдельный эксперимент.

## Воспроизводимость

Проверено: RTX 3090, CUDA PyTorch `2.14.0+cu126`, ONNX Runtime `1.30.0` (CPU),
4 CPU-потока. Версия native-конвейера `native-hybrid-v1-295197c2e351`,
каталога `7f8d342896c35157`. Экспорт проверяет численное совпадение оригиналов и
TorchScript на пяти ширинах вырезок, а также разные пары в пакетах 1/2/5/16.

```bash
# После запуска API со статической сборкой; из apps/shelf-finder:
node scripts/audit-server-browser.mjs /path/to/vitrini artifacts/server-browser \
  photo_2026-09-24_17-33-43.jpg photo_2026-09-24_17-33-59.jpg photo_2026-09-24_17-34-31.jpg
SHELF_AUDIT_BROWSER=webkit node scripts/audit-server-browser.mjs \
  /path/to/vitrini artifacts/server-webkit \
  photo_2026-09-24_17-33-43.jpg photo_2026-09-24_17-33-59.jpg photo_2026-09-24_17-34-31.jpg
```

Нужны установленные Playwright Chromium/WebKit и системные зависимости. Скрипт
сохраняет ответы, время полного пути и снимки интерфейса. Текущие локальные результаты:
`artifacts/server-browser-final/`, `artifacts/server-webkit-final/`;
прямой HTTP — `artifacts/server-http-v2/results.json`. Артефакты исключены из Git.

Проверки кода: **8 API-тестов, 23 TypeScript-теста, 5 браузерных тестов**, сборка
TypeScript/Vite. Покрыты повреждённые/слишком большие загрузки, EXIF, готовность,
занятость GPU, отмена ожидания, серверный UI и прежний локальный режим.

На iPhone остаётся проверить HTTPS, камеру и передачу по Wi-Fi/LTE. Эти три замера
укладываются в 10 секунд на localhost; SLA 10 секунд для любой витрины и сети нет.
Одновременный второй запрос получает 503 с `Retry-After`, а не стоит в очереди.
