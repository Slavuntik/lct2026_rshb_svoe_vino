# Проверка браузерного распознавания — 24 сентября 2026

Проверена production-сборка отдельного `shelf-finder`, режим `hybrid`, весь
каталог организаторов: 2103 позиции. Инференс выполнялся в Chromium через
ONNX Runtime Web (backend `webgpu`, 2 потока), с мобильным viewport.
Это браузер на сервере, **не физический телефон**.

Это малый набор, использованный при разработке, а не независимая тестовая
выборка. Результат нельзя переносить на весь датасет без отдельной проверки.

и JD Winery в итоговом прогоне не приняты.

## Воспроизводимость и проверки

Исходные результаты: `artifacts/browser-release/results.json`; сравнение:
`artifacts/browser-release/evaluation.json`. Аудит использует чистый браузерный
контекст, не читает ручную разметку для инференса. Ошибок страницы и внешних
запросов не зарегистрировано. Эталоны и модели загружаются с того же сервера;
фотографии обрабатываются локально.

`npm test`: 20 тестов; `npm run test:browser`: 3 регрессионных теста baseline;
`npm run build`: TypeScript и production-сборка успешно завершены.
Linux WebKit с размером экрана iPhone (390 px), без WebGPU, распознал одну вырезку
AGORA Bastardo за 3,55 с. Ошибок страницы, внешних запросов и горизонтального
переполнения нет. Это не проверка скорости полной витрины, нагрева или памяти на iPhone.

Зелёные примеры в корне исходного проекта `LCT 2026`: `browser_auto_01_shato_taman.png`,
`browser_auto_02_agora.png`, `browser_auto_03_vert.png`. Они построены исключительно
из браузерных результатов. Предыдущие примеры сохранены в
`artifacts/browser-baseline-root-examples/`.
