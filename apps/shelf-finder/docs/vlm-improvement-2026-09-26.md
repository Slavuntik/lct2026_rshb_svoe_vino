# Улучшение Qwen 27B с кандидатами каталога

## Что изменено

Проверены два новых варианта на той же `qwen3.8-27b` через пользовательский
LiteLLM. Рабочие API и модели витрин не переключались.

1. **Расширенный каталог** (`audit_vlm.py --mode guided-fields`): цвет,
   сорта, сахар и другие структурированные атрибуты вместе с названием.
   Добавлены требования различать одноимённые версии и не выводить
   производителя только из названия сорта.
2. **Сравнение с фотографиями** (`audit_vlm_references.py`): для каждого
   запроса показываются исходная бутылка и пять эталонных фото каталога,
   плюс увеличенные нижние части этикеток. Кандидаты перемешаны стабильным
   хешем, позиция визуального лидера не раскрывается. За запрос — три бутылки;
   модель должна назвать видимое отличие от ближайших конкурентов.
3. **Подтверждение геометрией** (`verify_vlm.py`): гипотеза остаётся
   подтверждённой, только если совпадает с принятым native-ответом либо
   проходит существующий `select_strong` на сохранённых ALIKED-результатах.
   Пороги не подбирались и не снижались. Другой уже принятый native-ответ
   не заменяется; неоднозначные native-SKU не превращаются в точные.
   Не прошедшие гипотезы сохраняются в `suggestions`.

В исходных ошибках две бутылки Grape Dance имели одно название в каталоге,
но разные цвет и фото. Ещё два ошибочных SKU выбирались по одному слову
Cabernet Franc. Реальные фотографии исправили путаницу Grape Dance, но
не устранили общую склонность модели выбирать похожую этикетку.

## Три исходных фото: 36 вырезок, 10 положительных меток

| Вариант | Правильно | Известные ошибки | Непроверенные принятые | Медиана LLM, с |
|---|---:|---:|---:|---:|
| Прежний Qwen + названия | 4 | 4 | 3 | 19,81 |
| Qwen + расширенные поля | 4 | 4 | 0 | 25,94 |
| Qwen + фото эталонов | 7 | 5 | 12 | 33,10 |
| Фото эталонов + геометрическая проверка | 4 | 0 | 0 | 33,10 |
| Native на тех же вырезках | 6 | 0 | 3 | отдельно для вырезок не измерено |

Фотографии повышают число верных гипотез, но без фильтра увеличивают и ошибки.
Все четыре подтверждённых Qwen-ответа уже были приняты native. Геометрия
не принесла дополнительных подтверждений через `select_strong`.

## Дополнительная проверка: 2 фото, 24 вырезки, 6 положительных меток

После фиксации промпта и правил проверены `photo_2026-09-24_17-33-59.jpg` и
`photo_2026-09-24_17-34-26.jpg`: раньше они не отправлялись в Qwen, но
присутствовали в прежних native-прогонах и частичной разметке. По результатам
этого прогона промпт и пороги не менялись.

| Вариант | Правильно | Известные ошибки | Непроверенные принятые | Медиана LLM, с |
|---|---:|---:|---:|---:|
| Прежний Qwen + названия | 2 | 2 | 0 | 31,00 |
| Qwen + фото эталонов | 3 | 5 | 15 | 43,02 |
| Фото эталонов + геометрическая проверка | 2 | 0 | 0 | 43,02 |
| Native на тех же вырезках | 5 | 0 | 0 | отдельно для вырезок не измерено |

Итого на пяти фото: прежний Qwen — 6 правильных и 6 известных ошибок;
вариант с эталонами и фильтром — 6 правильных и 0 известных ошибок.
**Это сокращение ошибок через отказ, а не увеличение числа распознанных
бутылок. Native нашёл 11 из 16 положительных меток на тех же областях.**
Заменять им native или фильтровать через Qwen все хорошие native-ответы
не следует: это потеряет правильные совпадения и добавит задержку.

## Формат и надёжность

Первый пилот без обязательного JSON уходил в объяснения и достигал лимита
ответа. Он остановлен и исключён из сравнения. Итоговый режим использует
`response_format=json_object`, системное требование краткого ответа и
проверку соответствия номера эталона конкретной бутылке. Неизвестные номера,
SKU вне списка, повторы и отсутствие обоснования не становятся совпадениями.
Оценщик запрещает считать незавершённый прогон полным и отдельно учитывает
ошибки запросов и отсутствующие ответы. В завершённых новых прогонах с
эталонами ошибок запросов и пропущенных вырезок не было.

Семь тестов проверяют порядок эталонов, привязку номеров к бутылкам,
неизвестные ответы, запрет оценки неполного прогона, геометрические пороги,
неизменность исходных гипотез и сохранение неоднозначности каталога.

## Ограничения и применение

Разметка частичная, создана прежним визуальным аудитом ИИ. Независимых
экспертных SKU/транскрипций нет. Время — сумма последовательных вызовов LLM
на фото, без локальной детекции и поиска кандидатов, подготовки коллажей и
браузера; проверки геометрии используют сохранённые признаки. Повторов для
оценки разброса не было, шлюз общий. Требование 10 секунд не достигнуто.

Новый режим полезен как **экспериментальная выдача гипотез с явным
подтверждением**, а не замена распознавателя. Для реального прироста далее
нужны крупные исходные снимки этикеток, проверенные различия близких SKU и
более сильное независимое подтверждение новых предложений. Само объяснение
Qwen, даже со словами «точное совпадение», подтверждением не считается.

## Воспроизведение

Из корня монорепозитория; пути к данным заменяются локальными:

```bash
pip install -r apps/shelf-finder/scripts/requirements-vlm.txt
python apps/shelf-finder/scripts/audit_vlm_references.py \
  --env-file .env --photos /path/to/vitrini \
  --files photo_2026-09-24_17-34-02.jpg photo_2026-09-24_17-33-43.jpg photo_2026-09-24_17-34-16.jpg \
  --native-results apps/shelf-finder/artifacts/accuracy/disagreement-comparison-disagreement.json \
  --catalog /path/to/catalog.jsonl --references /path/to/artifacts/index/reference_views \
  --output apps/shelf-finder/artifacts/vlm/qwen-references.json
python apps/shelf-finder/scripts/verify_vlm.py \
  apps/shelf-finder/artifacts/vlm/qwen-references.json \
  --native-results apps/shelf-finder/artifacts/accuracy/disagreement-comparison-disagreement.json \
  --output apps/shelf-finder/artifacts/vlm/qwen-references-verified.json
python apps/shelf-finder/scripts/evaluate_vlm.py \
  apps/shelf-finder/artifacts/vlm/qwen-references-verified.json \
  --dataset apps/shelf-finder/evaluation/shelves-v1.json \
  --native-results apps/shelf-finder/artifacts/accuracy/disagreement-comparison-disagreement.json \
  --output apps/shelf-finder/artifacts/vlm/qwen-references-verified-score.json
PYTHONPATH=apps/shelf-finder/scripts python -m pytest \
  apps/shelf-finder/scripts/test_vlm_references.py \
  apps/shelf-finder/server/tests/test_vlm_audit.py -q
```

[Метрики, контрольные суммы и расход токенов](../evaluation/vlm-improvement-2026-09-26.json).
Сырые ответы и входные коллажи находятся в игнорируемом `artifacts/vlm/`.
Пример зелёной разметки подтверждений — `example-reference-confirmed.jpg`;
неподтверждённые предложения на нём не отмечены. Секреты и изображения в Git
не включены. Скрипты отправляют снимки и эталоны только при явном запуске.
