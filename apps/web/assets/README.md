# Ассеты

Сюда кладём графику. Дизайн ещё не пришёл — папки уже готовы.

```
assets/
  logos/    ← логотип «Своё Вино», иконка сканера, favicon
  labels/   ← референсные фото этикеток (индекс для мок-матчера)
  brand/    ← фоны, паттерны, прочая айдентика
```

Правила:

- имена файлов латиницей, kebab-case: `svoe-vino-logo.svg`
- этикетки лучше называть как slug вина: `fanagoria-cabernet-sauvignon-2022.jpg`
- после добавления этикетки дописать её в `backend/data/label-index.json`

Фронт и бэкенд отдают эту папку как статику (`/logos/...`, `/labels/...`, `/brand/...`).
