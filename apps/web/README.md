# Vinlab — сканер этикеток «Своё Вино»

Модуль каталога: фото этикетки → одна карточка вина.  
Модель CV не входит в этот репозиторий: бэкенд имитирует её ответ, но **форматы запросов, JSON и сценарии — боевые**. Подмена мока на реальную модель не ломает фронт.

## Что умеет

1. Загрузка этикетки с камеры или из галереи (mobile-first веб).
2. Анализ изображения и поиск позиции в каталоге.
3. Одна карточка вина + метрики уверенности F1 (top-1 / top-5) в API.
4. Если вина нет в каталоге — аналоги из других виноделен или честный «не найдено».
5. Цифровой сомелье: несколько вопросов → рекомендация (retention).
6. Эндпоинт `/eval` для скрипта оценки: `{"slug":"wine-slug"}`.

## Быстрый старт

Команды из папки `vinlab/frontend`.

```bash
bash start.sh
```

Скрипт ставит зависимости, если их ещё нет, и поднимает фронт и локальный API. То же самое: `npm install && npm run dev`.

- UI: http://localhost:5173
- API: http://localhost:3001
- Health: http://localhost:3001/api/health

Оценка (как у организатора):

```bash
curl -s -F "image=@./e2e/fixtures/fanagoria-cabernet.png" http://localhost:3001/eval
# {"slug":"fanagoria-cabernet-sauvignon-2022"}
```

E2E:

```bash
npm run test:e2e
```

## Принцип мока

Матчер не «угадывает нейросетью». Он:

- считает SHA-256 файла и ищет в индексе референсных этикеток;
- иначе матчит по имени файла (удобно для тестов и скрипта оценки);
- иначе возвращает `found: false` и подборку аналогов.

Когда появится настоящая модель — заменить только `backend/src/matcher.ts`. Контракт `ScanResult` не меняется.
