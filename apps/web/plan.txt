Контекст
--------
Делаем полный фронт + бэкенд модуля сканера этикеток для портала «Своё Вино».
Модель CV/OCR не обучаем: матчер мокнутый, но контракты запросов, JSON и UX — как в бою.
Дизайн (макеты) придёт позже; сейчас — рабочий mobile-first каркас.

Стек
----
- Frontend: React + TypeScript + Vite + React Router
- Backend: Node.js + Express + TypeScript
- Каталог: JSON (без БД на этом этапе)
- E2E: Playwright
- Ассеты: папка assets/ (логотипы, этикетки, бренд)
