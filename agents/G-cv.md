# Агент G · CV-ядро сканера (кейс)

**Зона:** `packages/cv/`, `reports/g-report.md`
**Контракты:** `contracts/image-scan.md` — реализовать в точности. Контекст кейса: `case.md`.
Метод: arXiv:2404.08820 — 3D-ракурсы из одного эталона, классический CV без GAN.

## Задача

Всё, что можно построить ДО приезда датасета кейса (он завтра, локально, в CASE_DATA_DIR):
аугментатор ракурсов, нормализация запроса, обвязка SigLIP 2, ImageIndex, CLI, замеры.

## Порядок

1. `uv venv` (Python 3.12). Зависимости: opencv-python-headless, numpy, pillow,
   transformers+torch (MPS), qdrant-client. PaddleOCR НЕ твоя зона (верификатор — отдельно).
2. **Аугментатор** (`cv/augment.py`): этикетка на цилиндр (радиус ~ бутылочный, варьируется),
   повороты по трём осям, перспектива, блики-полосы, расфокус, шум, фон (полка/рука),
   вариации экспозиции. Детерминированно по seed. Из 1 изображения ≥ 20 ракурсов.
3. **Нормализация запроса** (`cv/normalize.py`): детект области этикетки (классика:
   контуры/цвет/градиенты — без обучаемого детектора в v1), кроп, обратная развёртка
   цилиндра, выравнивание освещения. Флаг отключения для A/B в eval.
4. **Энкодер** (`cv/encoder.py`): SigLIP 2 через transformers; выбор чекпойнта по замеру
   на MPS и CPU (цель: embed ≤ 300 мс/фото на MPS); кэш эмбеддингов на диске.
5. **ImageIndex** по контракту: qdrant_embedded бэкенд; мульти-ракурсная укладка,
   схлопывание ракурсов в позиции, gap до чужой группы; манифест версии.
6. **CLI**: `cv build-index --refs <dir|csv> --version`, `cv search <photo>`,
   `cv bench` (тайминги), `cv selfcheck` (self-match аугментаций, см. DoD контракта).
7. **Дев-фикстуры**: скачай ВЕЖЛИВО (1 rps, User-Agent проекта) 50–60 фото бутылок по
   `image_url` из `pipeline/catalog/wines/*.json` — в том числе ОБЕ пары near-duplicates
   (aligote-barrel-2024/2025 ищи по slug'ам с суффиксами годов) — в `packages/cv/devfix/`
   (добавь в .gitignore пакета). На них: визуальная проверка нормализации, self-match,
   замеры. Это НЕ датасет кейса — только дев-фикстуры.
8. Селфчек-цифры в отчёт: self-match top-1 rate по аугментациям, p95 embed, p95 полного
   search на индексе из фикстур.

## Тесты (pytest)

- аугментатор детерминирован по seed; ≥ 20 ракурсов; размеры валидны;
- self-match: аугментация эталона находит свой slug top-1 на индексе фикстур (≥ 90% на дев-наборе);
- near-dup: пара 2024/2025 попадает в одну группу кандидатов (различать будет OCR — не ты);
- ImageIndex.add: новый slug ищется без ребилда;
- search на битом файле → ValueError, не 500-полуфабрикат.
