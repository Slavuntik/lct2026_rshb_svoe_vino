# Архитектор · TCO сканера по конфигурациям железа (стратегия Вячеслава, 22.09)

**Зона записи:** `docs/strategy/tco.md`, `reports/architect-tco.md`.

## Что нужно

Таблица «конфигурация → точность → задержка и пропускная способность → стоимость в месяц и за
1000 распознаваний → TCO за год», с честными оговорками. Цель — показать жюри и заказчику цену
каждой десятой процента точности и предложить комбинации.

Конфигурации (обязательные): (1) VDS 4 vCPU без GPU — как стенд ams3; (2) VDS/сервер 16 vCPU;
(3) сервер с 2× RTX 3090 (аренда и покупка); (4) Mac mini M4 / Mac Studio как локальный узел
инференса (локальная Qwen3-VL-4B); (5) гибрид: CPU-стенд + наш GPU-сервер с 27B через шлюз;
(6) гибрид: Mac + GPU-сервер (обе модели). Для каждой: точность top-1 на 62 живых фото ТОЛЬКО из
измеренного, задержка на фото, оценка пропускной способности (фото/час при последовательной
обработке и при разумной параллельности), RAM/диск, риски (доступность, обслуживание).

## Измеренное (не выдумывать, ссылаться)

- 4 vCPU (ams3, KVM, AVX2): CPU-путь hack-v8 91.9%, медиана 4.1 с, p95 4.8 с, max 5.7 с; RSS API 1.9 ГБ
  (`qa/scan-eval-runs/real-photos-stand/README.md`). Кандидат hack-v9 (чувствительный детектор): офлайн
  95.2% — до приёмки qa-auto считать «ожидается», пометить.
- Mac M5 (Apple Silicon): CPU-путь ~1 с; локальная Qwen3-VL-4B 91.9% при ~3 с; обе модели (4B + 27B через
  шлюз) 95.2–96.8% при 4.4–5.3 с (`reports/cpu-path-study.md`, `reports/label-crop-study.md`,
  `contracts/image-scan.md` v0.4.13 п.6, `qa/scan-eval-runs/real-photos-stand/README.md`).
- GPU-сервер (27B за шлюзом): чтение этикетки ~4 с последовательно, хвост до 10 с при 4 параллельных
  запросах; 27B без OCR — 93.5–95.2% через живой API.
- Qwen3-VL-2B/4B на 4 vCPU (llama.cpp): 4.7–8.4 с и точность 73–87% — на CPU модель не окупается
  (`reports/cpu-path-study.md` §2–3).
- 16 vCPU — замера нет: оценка пересчётом (эмбеддинги и OCR масштабируются почти линейно), так и
  подписать «оценка».

Цены — из открытых источников (российские провайдеры VDS/GPU-серверов, розница Mac mini/Studio,
цена RTX 3090 б/у), каждая с ссылкой и датой; электричество и обслуживание для покупки — оценка с
допущениями, явно записанными. Валюта — рубли; при курсе указать дату.
