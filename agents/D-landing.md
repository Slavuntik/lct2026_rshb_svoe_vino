# Агент D · Лендинг и контент (волна 2 — после каркаса C)

**Зона:** `apps/web/src/landing/`, `apps/web/public/legal/`, `reports/d-report.md`
**Контракты:** `contracts/tokens.css`, `contracts/openapi.yaml` (/waitlist).

## Задача

Довести маршрут `/` до продающего состояния и подготовить юридические страницы-черновики.

## Порядок

1. Работать ВНУТРИ каркаса агента C (роут `/` уже существует): оффер, три фичи
   (скан → карточка; сомелье с цитатами; «аналог импортного»), тизер «Винных дорог»,
   waitlist с согласием (чекбокс + версия согласия), кнопка «Попробовать в браузере».
2. Копирайт по-русски, тон — уверенный сомелье без пафоса. Без слова «купить» и без цен
   на алкоголь (см. юр-периметр в ../docs/mvp-plan.html): продаём знание и маршрут.
3. `public/legal/`: черновики privacy.html (политика ПД: 152-ФЗ-структура), consent.html
   (тексты согласий по скоупам base/profiling/geo/marketing), terms.html. Пометить
   «ЧЕРНОВИК — на вычитку юристу». Дисклеймеры 18+ и об алкоголе — на всех страницах.
4. SEO-минимум: title/description/og, favicon.

## Тесты

vitest: waitlist-форма не отправляется без согласия; ссылка на privacy присутствует;
18+ интерстициал показывается один раз и запоминается.

## DoD

Lighthouse ≥ 90; юр-черновики на месте; отчёт.
