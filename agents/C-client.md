# Агент C · Клиент: веб + iOS одним кодом

**Зона:** `apps/web/`, `apps/shell/`, `reports/c-report.md`
**Контракты:** `contracts/openapi.yaml` (клиент API), `contracts/tokens.css` (единственный
источник цветов/шрифтов), `contracts/events.md` (клиентские события).

## Задача

React + TypeScript + Vite PWA: лендинг (маршрут `/`) + приложение (маршрут `/app`),
Capacitor-оболочка для iOS/Android. Шесть экранов, ни одним больше.

## Порядок

1. Vite + React + TS + react-router. Все строки интерфейса — через i18n-слой
   (простой словарь ru.ts + пустой en.ts, свой хук; ни одной строки в JSX хардкодом).
   tokens.css импортируется как есть; шрифты Google Fonts (Cormorant + IBM Plex).
2. Экраны `/app`: онбординг (18+ дата рождения, согласия по скоупам — тексты-черновики
   пометить TODO-юрист), скан, карточка вина, чат (SSE), паспорт вкуса (свайпы),
   профиль («мои данные»: выгрузка, удаление). Лендинг `/`: оффер, три фичи, waitlist,
   кнопка «Попробовать в браузере» → /app, 18+ интерстициал, дисклеймер об алкоголе в футере.
3. API-клиент генерится или пишется руками строго по openapi.yaml; MSW (mock service worker)
   с фикстурами из 6 вин — приложение полностью живёт без бэкенда (env VITE_API_MODE=mock|real).
4. Скан: в вебе — file input/камера → предупреждение о согласии → POST /scan/ocr (мок);
   поле «ввести текст с этикетки» как равноправный путь (он же — путь iOS до готовности плагина).
5. Capacitor: init в apps/shell, webDir на сборку apps/web; конфиг iOS (bundle id — плейсхолдер
   `ru.svoysomelye.app`, поменяем на publish-Mac). Плагин OCR: создать каркас плагина
   (интерфейс TS + заглушка Swift-файла Vision с TODO) — сборка iOS НЕ на этой машине,
   Xcode здесь нет; главное — чтобы `npx cap sync ios` проходил.
6. PWA: manifest, иконка-плейсхолдер, offline-заглушка «нет сети» без крэша.

## Тесты (vitest, обязательны)

- онбординг: без даты рождения/до 18 — дальше не пускает; скоупы уходят в API-клиент.
- чат: SSE-парсер собирает token/citation/done; refusal рендерится честным текстом.
- скан: текстовый путь → resolve → карточка; low_confidence → список выбора.
- свайпы шлют события по словарю events.md (шпион на клиенте аналитики).
- i18n: тест «в JSX нет кириллицы вне словаря» (грубый grep-тест по src — допустим).

## DoD

`npm run dev` поднимает всё в mock-режиме; `npm run build` зелёный; `npx cap sync` проходит;
vitest зелёный; лендинг Lighthouse ≥ 90 perf (замерить локально, число в отчёт).
