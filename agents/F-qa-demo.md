# Агент F · QA, демо-паки и сквозные сценарии (волна 2)

**Зона:** `qa/`, `reports/f-report.md`
**Опора:** план `../docs/mvp-plan.html` (раздел 0 — критерии демо), данные vines read-only.

## Задача

Генератор демо-паков, сквозные сценарии и приёмочный прогон demo-ready.

## Состав

1. `qa/demo_pack.py` + `make demo-pack WINERY=<slug>`: из каталога vines собрать пак:
   - бутылки: топ-8 винодельни по полноте карточки и рейтингу (поля-минимум: name, color,
     sugar, grapes, food_pairings, description, image);
   - сценарий трёх сцен (скан → вопрос сомелье → аналог импортного) с ожидаемыми
     карточками и цитатами; вопросы — из реальных гастропар пака;
   - автопроверка: все обязательные поля непусты, source_url отвечает 200 (HEAD, вежливо),
     аналог для сцены 3 существует в derived;
   - выход: `qa/packs/<winery>/pack.md` (человеку) + `pack.json` (машине).
   Первый пак: `abrau-dyurso`. Второй, для проверки универсальности: любая другая винодельня.
2. Сквозные сценарии `qa/e2e/` (playwright, против mock-режима клиента C):
   онбординг с гейтом 18+ → скан текстом → карточка → чат с цитатой → свайпы → профиль/удаление.
   Если каркас C ещё не готов — сценарии пишутся по контрактам как исполняемая спецификация
   и помечаются skip до интеграции.
3. `qa/demo-script.md`: 15-минутный сценарий показа по треём сценам пака, с репликами,
   таймингом, планом Б (веб-версия) и планом В (запись экрана).
4. Приёмочный чек-лист demo-ready 10.09: критерии из раздела 0 плана, каждый — команда
   или наблюдаемый факт, не мнение.
