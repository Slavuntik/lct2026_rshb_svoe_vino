## Задачи

1. **CLI-расширение** `cv build-index`: принять `--refs-json case-data/slug_refs.json
   --uploads-dir <path>` (первый файл слага = эталон; если files>1 — берётся первый,
   остальные добавляются доп-ракурсами view="real-2..").
2. **Собрать боевой индекс** версии `case-20260916` со ВСЕМИ доступными слагами из
   slug_refs.json: замерить время сборки (стадии: augment/normalize/embed/upsert),
   пиковую память, размер на диске. Эмбеддинг-кэш обязателен (пересборка после
   довеска F3 должна быть дёшевой).
3. **Замеры поиска на боевом масштабе**: p50/p95 search (MPS), включая нормализацию
   запроса. Сравни с бюджетом ≤3 c и прежними 31 мс на мини-индексе.
4. **Self-match на реальных эталонах**: сэмпл ≥300 слагов, по 2 синтетических ракурса
   (не из индекса, свежий seed) → top-1 rate свой slug, top-5 rate. Это zero-shot
   нижняя граница на ИХ данных.
5. **Gap-статистика near-dup**: для пар, разделяющих ОДИН файл-эталон
   (`aligote-barrel-2024/2025` и др. — список в slug_refs.json как photos с
   несколькими слагами / у F3 в families.json): подтверди gap≈0 (неразличимы по CV
   принципиально); для семей с РАЗНЫМИ фото — распределение gap. В отчёт: у каких семей
   CV вообще имеет сигнал, у каких решает только верификатор/tie-break.
6. **Smoke: 3 полевых фото** `case-data/eval/queries/` прогони через `cv search`
   (с нормализацией и без): top-5 slug+score+gap в отчёт. Проверь по CSV кейса, есть ли
   в каталоге сами вина (Табия Пино Нуар полусухое 2025; Мускатель Массандра Белый 2023;
   Aristov Donum XXIV брют 2023) — если да, укажи, каким рангом нашлись. На фото есть
   ЧУЖИЕ бутылки в кадре (полка!) — задокументируй, что выбрал детектор этикетки.
   Это smoke-проверка, НЕ тюнинг: пороги/параметры не менять.
