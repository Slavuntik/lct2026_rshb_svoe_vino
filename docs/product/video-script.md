# Сценарий видео ≤7 минут — демо на живом стенде

Требование кейса: питч ≤7 минут, порядок — концепция → архитектура пайплайна → живое демо без
монтажа → метрики F1 топ-1/топ-5 → доп-функция → выводы (`case.md` строки 76–77); демо — без
склеек, эксперты сами меряют скорость. Заменяет/обновляет черновик `docs/video-demo-scenario.md`
(тот писался 17.09 под `localhost:5173` и синтетику 1982 позиций до прихода живых фото
организаторов) — демо теперь на публичном стенде **http://89.110.72.101** (жив на 22.09,
`/v1/healthz` → `warm:true`, `cv_index_version=case-20260921-d1-b384` — проверено вживую при
подготовке этого сценария).

Реквизит: 2–3 бутылки, из них минимум одна — из линейки, где есть «близнец» (тот же дизайн
этикетки, другой год/сахар/категория, например семья «Табия» — `reports/h1-cpu-path.md`,
`reports/d1-ref-collisions.md`), одна заведомо не из каталога (импорт); стенд прогрет заранее;
браузер на вкладке стенда + вкладка `http://89.110.72.101/v1/metrics/scan`; таймер в кадре.

## Хронометраж (7:00)

**0:00–0:30 — Концепция.** «Покупатель фотографирует этикетку у полки — сервис должен вернуть
ОДНУ карточку вина из каталога „Своё Вино", без экрана вариантов (как в Vivino, `case.md`
строка 8). Каталог — 2103 позиции. Главная трудность — не «узнать бутылку», а разлепить
близнецов: одна серия, разный год или сахар при одинаковой этикетке (`case.md` строка 33,
«near-duplicates — главный источник ошибок»)».

**0:30–1:15 — Архитектура (1 слайд, `ARCHITECTURE.md`/слайд 8 презентации).** Фото →
нормализация (кроп, развёртка цилиндра) → эмбеддинг SigLIP2 → ANN по мульти-ракурсному индексу →
схлопывание в позиции → слияние CV-скора с текстом этикетки, сверенным со ВСЕМ каталогом (не
только с похожими) → калиброванное решение (`contracts/image-scan.md` v0.4.13). Один пайплайн
отдаёт и `{"slug":...}` для скрипта оценки, и полную карточку для интерфейса.

**1:15–4:00 — Живое демо на стенде, без монтажа.**
1. *(1:15–2:15)* Сканируем бутылку из каталога, у которой есть визуальный «близнец» другого
   года/сахара → одна карточка. Проговорить: «текст на этикетке сверился со всем каталогом,
   не только с похожими на вид — это и отличает близнецов» (`contracts/image-scan.md` v0.4.13
   §2). Показать карточку целиком: фото, винодельня, описание, ссылка «Открыть на «Своё Вино»»
   (`reports/c3-candidates-ui.md`).
2. *(2:15–3:00)* Сканируем вино НЕ из каталога (импорт) → честное «нет в каталоге» +
   блок **«Возможно, это одно из:»** (кандидаты — ближайшие вина каталога с фото и винодельней,
   `contracts/image-scan.md` v0.4.11, `reports/b8-candidates-card.md`, `reports/c3-candidates-ui.md`)
   + ниже — **«Аналоги из других виноделен»** (аналоги по стилю среди российских вин — то, что
   кейс «оценивает особенно высоко», `case.md` строка 24). Если под рукой окажется импортный
   рислинг/шардоне — показать текстовый разбор «иностранное → российский аналог»
   (`reports/b7-foreign-analogs.md`).
3. *(3:00–4:00)* С любой карточки — кнопка **«Спросить сомелье»**: один содержательный вопрос
   (например, про сочетание с блюдом или про вкус) → ответ с цитатой-ссылкой на первоисточник
   (`ARCHITECTURE.md` шаг 5, гибридный RAG). Проговорить честно: если на стенде в этот момент
   не подключён ключ GigaChat — ответ придёт от заглушки; статус ключа проверить заранее по
   чек-листу ниже (`infra/ams3/README.md`, `docs/product/post-scan.md`).

**4:00–5:00 — Метрики (вкладка `/v1/metrics/scan`, требование «F1 в API», `case.md` строка 22).**
Прочитать с экрана живые цифры: топ-1 **91.9%** на 100 живых фото организаторов (62 вина есть в
каталоге), путь — CPU без сети, RapidOCR в два масштаба, ни одного ответа дольше 6 секунд при
лимите скрипта 10 с (`qa/scan-eval-runs/real-photos-stand/README.md`). Честно: «топ-5 в этом
прогоне не считается (flat-режим скрипта меряет только топ-1) — посчитан отдельно на
rich-режиме» (уточнить актуальное число перед записью — см. слайд 9,
`docs/product/slides-7-11.md`). С подключённой моделью на этом же наборе — **95.2%**
(`contracts/image-scan.md` v0.4.13 §6).

**5:00–6:00 — Доп-функция (ретеншн, вес критерия 20/100, `case.md` строка 84).** Сомелье-чат с
цитатами, аналоги российских вин иностранным, вкусовой профиль по свайпам (7 осей вкуса,
`contracts/openapi.yaml` `/taste/profile`) — коротко показать один экран паспорта вкуса, если
успеваем по хронометражу; если нет — оставить на словах со ссылкой «работает, показано в
приложении к репозиторию» (подробный статус — `docs/product/post-scan.md`).

**6:00–7:00 — Выводы, честно.**
- «Наш потолок — не 100%, а потолок каталога: у 2054–2058 из 2103 позиций вообще есть
  пригодное эталонное фото (**97.7–97.9%**, `reports/f4-data-hygiene.md`,
  `reports/d1-ref-collisions.md`) — выше этого не поднимется ни одна система без новых фото
  от площадки».
- «На дешёвом CPU без сети мы закрываем 94% от этого потолка (91.9%), с одной моделью на GPU —
  97% (95.2%) — decision по железу и цене вопроса разобран в приложении
  (`docs/product/strategy.md`)».
- «Близнецы одной линейки остаются главным источником оставшихся ошибок — decode текста
  этикетки помогает, но не отменяет: чем мельче различающее слово на фото, тем выше шанс
  ошибиться» (`reports/label-crop-study.md`, `reports/l-real-labels-part1.md`).
- «Всё воспроизводимо: открытый репозиторий, README и ARCHITECTURE.md, метрики отдаются живым
  API, а не только на слайде» (`README.md`, `ARCHITECTURE.md`).

## Отклонение от типового шаблона (на решение тимлида)

Типовой сценарий (`docs/video-demo-scenario.md`, 17.09) отводил отдельный блок на запуск
`participant_test.sh` в терминале. Здесь этот блок сознательно убран из 7-минутного видео:
по `case.md` (строка 66) контрольный прогон скрипта на приватных данных — отдельное событие
«на звонке», а не часть ролика; освободившееся время отдано кандидатам и сомелье-чату, которые
явно запросил тимлид. Если тимлид хочет вернуть терминал в кадр — это ещё 60–80 секунд, тогда
предлагаю сжать раздел «Выводы» до 30 секунд.
