# Проверка интеграции полок — 27.09.2026

## Реализовано

Основной экран `/app/shelf` использует общие фильтры сомелье, каталог и гастропары.
Новый API `/v1/sommelier/shelf-selection` ранжирует найденные слаги; отдельный CV-сервис
не зависит от пожелания. Поддержаны восемь фото, последовательная очередь, общий рейтинг,
повтор отдельного фото, остановка очереди и сохранение результатов при отказе health.
Из чата передаётся последняя пользовательская реплика; полный контекст/вкусовой профиль
не передаются. Все десять замечаний адверсариального ревью исправлены отдельными регрессиями.

API проверялся из `apps/api` с `PYTHONPATH=../../packages/llm:../../packages/rag:../../packages/cv`.
Основное `.venv` не содержит OpenCV; к Python search path в конце добавлены уже установленные
зависимости отдельного ML-окружения. Изначальные девять падений импорта `cv2` исчезли
после этого. Зависимости не скачивались, модели и внешние API не вызывались.
Предупреждения: два deprecated API Starlette/AnyIO и неизвестный `asyncio_mode`.

Браузерный тест находится в `apps/shelf-finder/tests/browser/integrated-shelf.spec.ts`,
конфигурация `playwright.integrated.config.ts`. Он проверяет настоящие UI, загрузку и
перекодирование изображений, последовательность запросов и восстановление интерфейса,
но подставляет ответы распознавания и ранжирования. В этом Linux-окружении WebKit
запускался с локальным launcher через `SHELF_WEBKIT_EXECUTABLE`; на обычной установке
Playwright переменная не требуется.

## Что этими тестами не доказано

Точность CV/Qwen, качество рекомендаций на размеченных реальных полках, скорость на
физическом iPhone, действительность LiteLLM-ключа, текущая конфигурация production proxy,
результат приватного скрипта кейсодержателя. Продакшен не перезапускался и не выкладывался.
