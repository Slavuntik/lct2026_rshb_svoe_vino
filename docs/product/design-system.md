# Общий интерфейс Vinchik

Источник реализации — `apps/web`. С 29.09.2026 визуальный эталон — предоставленный пользователем `temp/web.zip`; [подробности переноса и снимки](reference-design-2026-09-29.md). Прежние датированные отчёты отражают историю до этого обновления.

## Карта рабочих интерфейсов

| Часть | Общие правила |
|---|---|
| Скан, каталог, чат, карточка, вкус, профиль | React `apps/web`, общая навигация, компоненты и словарь `src/i18n/ru.ts` |
| Полки `/app/shelf` | Экран основного приложения: пожелание → несколько фото → ранжирование → общая карточка вина |
| Расширенный сканер `/shelf-ui/` | Собственная сборка; напрямую импортирует базовые стили `apps/web`, использует его кнопки, палитру, шрифты и логотип; есть возврат в подбор сомелье |
| Мобильная оболочка `apps/shell` | Использует `apps/web/dist`, отдельного мобильного дизайна нет |
| Юридические страницы `/legal/*` | Статический HTML; Vite автоматически выдаёт общие токены/шрифты в dev и build |

`design/ui-prototype` и `standalone/winescan` — исторические прототипы/снимки,
не маршруты действующего приложения. Их самостоятельный редизайн не входит в
распространение дизайна продукта; `standalone/winescan` сохраняет совместимость
со своим исходным репозиторием. Backend, Swagger и экспериментальные отчёты не являются
пользовательскими экранами портала.

## Первый вход и возрастное предупреждение

Корень `/` перенаправляет на `/app/scan`. Старый лендинг не участвует в маршрутизации. При первом входе `/app/onboarding` показывает нижнюю белую панель 18+ поверх размытого, недоступного для взаимодействия сканера. Кнопка «Подтверждаю» подтверждает совершеннолетие и создаёт гостевую сессию; дата рождения не запрашивается. Оформление соответствует предоставленному скриншоту от 29.09, детали и тесты — в [отчёте UI](reference-design-2026-09-29.md).

## Источник истины

- `apps/web/src/styles/tokens.css`: палитра, размеры текста, интервалы, радиусы,
  семантические цвета разметки фотографий. Новые цвета добавляются сюда, не в экраны.
- `apps/web/src/styles/global.css`: карточки, поля, кнопки, состояния и раскладка.
- `apps/web/src/styles/reference.css`: актуальная композиция из архива, подключается после базовых стилей; ширина 440 px, шапка, сканер, карточки, адаптация остальных рабочих экранов.
- `apps/web/src/styles/fonts.css` и `src/assets/fonts`: локальные Inter,
  Playfair Display, IBM Plex Mono. Подключение без Google Fonts/CDN, `font-display: swap`.
  32 файла шрифтов и три лицензии SIL OFL, около 578 KB исходных ресурсов;
  браузер загружает только нужные начертания и Unicode-подмножества.
- `themes/portal.css`: совместимый alias общей темы, без второй копии палитры.
- `vite.config.ts`: юридические страницы получают токены и шрифты из тех же исходников;
  ручная копия `public/legal/tokens.css` удалена.

Рабочие интерфейсы светлые независимо от темы устройства. Макета тёмного режима нет;
в токенах сохранены прежние значения для будущего явного включения. Нельзя включать
системное переключение только на одном экране. Основные touch-кнопки минимум 44 px,
цвет не заменяет текст ошибки/статуса, фокус должен быть видимым.

## Общая логика

Показывайте задачу пользователя перед техническими настройками. На полках основные
действия — пожелание и фото; выбор движка, пороги и диагностика находятся в раскрываемых
разделах расширенного сканера. Не смешивайте предварительный подбор и реально найденные
вина. Ошибка одной фотографии не должна стирать другие; повторяется только неудачный шаг.
Карточки ведут в `/app/wine/:wineId`, сомелье использует общий каталог и гастропары.
Зелёная подсветка означает подтверждённое совпадение, неоднозначный SKU явно помечается.

## Сборка и перенос

Обе сборки запускаются из полного checkout монорепозитория:

```bash
npm --prefix apps/web ci
npm --prefix apps/web run build
npm --prefix apps/shelf-finder ci
npm --prefix apps/shelf-finder run build
docker build -f apps/shelf-finder/Dockerfile -t vinchik-shelf-ui .
```

Для сборки shelf UI требуется исходник общих стилей/шрифтов/логотипа `apps/web`,
но не установка его npm-зависимостей. Полученный `apps/shelf-finder/dist` автономен:
его можно перенести вместе с отдельным CV-сервисом. Контекст Docker — корень монорепо.
Для браузерного инференса комплект моделей нужно подготовить отдельно; server mode
нуждается в прокси `/v1/shelf/*`. Сам nginx-образ UI не запускает Python/GPU API.

Статические legal-страницы публикуйте из `apps/web/dist`: прямое копирование одной
папки `public/legal` не включает сгенерированные общие ресурсы.

## Верификация

Обход scan/catalog/chat/taste/profile/wine в Chromium и WebKit, 390×844, системная
тёмная тема: единые цвета, загруженный Inter, отсутствие горизонтального переполнения
и ошибок JavaScript. Это smoke UI с demo API, не проверка реальных аккаунтов/моделей.
Браузерные тесты полок проверяют загрузку, очередь, отказ сервиса, повтор, единые
токены, локальные шрифты и legal-страницы. Screenshot-артефакты сохраняются локально в
`apps/shelf-finder/artifacts/ui-*.png`; они не входят в Git.

После объединения с `248082d`: 210 frontend-тестов, production-сборки обоих UI,
4 интеграционных и 8 standalone браузерных проверок успешны. Docker-образ
собран на чистом наборе исходников. Старые копии токенов заменены общим источником,
остальные изменения коллег в карточках/скане/навигации сохранены.
