тесты и конфигурации побайтово. Адаптер `winescan/integration` остаётся только
в `packages/winescan`. Внешний источник можно указать явно:
`WINESCAN_SOURCE='/home/user/work/LCT 2026' make winescan-sync-check`.
Снимок автономного проекта сохранён без изменений поведения; его README и
архитектура описывают состояние на 17 сентября, а текущая схема синхронизации — здесь.

## Совместимость движков

`IMAGE_PROVIDER=real` сохраняет новый путь CV/VLM, включая `CV_FUSION`.
`IMAGE_PROVIDER=winescan` использует собственное слияние внутри WineScan:
флаг `CV_FUSION` родного движка к нему не применяется. Прогрев WineScan теперь
действительно вызывает поиск; отсутствие галереи отражается в состоянии прогрева.
Настройки провайдера по умолчанию не менялись. Старые сравнительные результаты
в `docs/scan-engines.md` относятся к версиям от 17 сентября и не доказывают
преимущество над обновлённым CV/VLM из текущей `main`.

Рамка доступна после первого поиска бутылки; переключение на блюдо сбрасывает её.
Подбор по фото блюда, категории, аналоги по вкусу и переход к сомелье сохранены.
