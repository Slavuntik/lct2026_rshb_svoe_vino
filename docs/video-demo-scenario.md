# Сценарий видео-демо ≤7 минут (отборочный этап, без склеек)

Требование ТЗ: живое демо без монтажа; эксперты меряют скорость сами. Один дубль,
один экран, таймер видим. Реквизит: 2 бутылки в кадре телефона (одна из каталога —
например Массандра из линейки, одна импортная), стенд поднят ЗАРАНЕЕ (прогрет),
браузер чист (localhost:5173 + вкладка /v1/metrics/scan), терминал с их скриптом.

## Хронометраж

**0:00–0:35 — Задача.** «Покупатель у полки фотографирует этикетку — сервис отдаёт
одну карточку из каталога „Своё Вино“. Главная сложность — near-duplicates: одна
серия, разные год и категория. Покажем живьём.»

**0:35–1:20 — Архитектура (1 слайд/ARCHITECTURE.md на экране).** Слои: нормализация
фото → SigLIP2-эмбеддинг → мульти-ракурсный ANN-индекс (эталон + 24 синтетических
3D-ракурса на позицию, метод arXiv:2404.08820) → схлопывание → OCR-верификатор
near-dup → калиброванное решение. Каталог 1982 позиции, 49 650 векторов.

**1:20–3:20 — Живой скан (браузер, мобильная вёрстка).**
1) Фото бутылки ИЗ каталога (Массандра «Мускатель Белый») → одна карточка;
   показать бейдж ocr_verified: «верификатор ПРОЧИТАЛ „Мускатель белый“ на
   этикетке и различил её среди 8 визуально одинаковых позиций линейки» —
   это ровно near-dup сценарий, на котором кейс проверяет достоверность.
2) **Полка с двумя бутылками** → сервис отвечает по одной из них, после ответа жмём
   «Покажите нужную бутылку», обводим рамкой соседнюю и «Искать по рамке» → карточка
   меняется на неё. Проговорить, почему это важно: узкое место у полки — не поиск, а
   выбор нужной бутылки. Идеальный выбор среди рамок детектора даёт top-1 0,775, а
   автоматический — 0,663, и вытащить признак «та самая бутылка» из кадра не удалось
   ничем; палец пользователя знает ответ точно.
3) Фото ИМПОРТНОЙ бутылки → честное «нет в каталоге» + похожие российские вина
   («оценивается особенно высоко» по ТЗ — проговорить).

**3:20–4:10 — Функция после поиска.** Текстовый запрос «Urban Riesling» → «в
каталоге российских вин отсутствует — аналоги по стилю: рислинг» → карточки
Абрау-Дюрсо/АРАТТИ/Бельбек. «Импортозамещающий сомелье: любой иностранной
этикетке подбираем российский аналог». + 2 реплики цифровому сомелье (RAG с
цитатами на первоисточник).

**4:10–5:00 — Метрики (требование ТЗ «F1 в API»).** Вкладка /v1/metrics/scan:
index_version, f1_top1/f1_top5 живые, с последнего прогона 1982 позиций. Озвучить
честно: «на синтетических ракурсах raw top-1 69%, top-5 90% — путь до 90+ описан:
детектор-интейк, верификатор, дообучение; финальная калибровка — на полевом
датасете».

**5:00–6:20 — Скрипт кейсодержателя, без правок.** В терминале:
`./participant_test.sh --images-dir queries --manifest queries.tsv --endpoint
http://127.0.0.1:8080/v1/eval/predict --output predictions.jsonl` → показать
predictions.jsonl и latency_ms (сотни миллисекунд против лимита 10 с; SLA ≤3 c —
запас ×5–20).

**6:20–7:00 — Выводы.** Одна карточка без экрана вариантов; near-dup решается
чтением этикетки, а не угадыванием; «нет в каталоге» — это фича с аналогами;
выбор бутылки у полки отдан пользователю там, где автоматика упирается в потолок;
всё воспроизводимо: открытый репозиторий, README/ARCHITECTURE, метрики в API.
Если спросят про движок распознавания: их в сервисе два за одним контрактом, и
умолчание выбирается замером на общей выборке, а не вкусом (`docs/scan-engines.md`).
