## 2. Принципы

1. **Сначала измерительная база.** Пока нет реальных фото, любое улучшение может быть подгонкой
   под генератор синтетики (SIFT: 135 inliers на синтетике против 5–87 на реальных фото).
2. **Каждое изменение — эксперимент** с метрикой на реальной и синтетической валидации; принимаем,
   только если реальная метрика не падает (раздел 4).
3. **Лицензии Apache / MIT / BSD** для всего, что уходит в продукт (RESEARCH.md, раздел 6).
4. **Точность важнее скорости** (50 против 5): дорогие стадии (VLM) вызываются только в полосе
   сомнения, чтобы укладываться в SLA 3 с.
5. **Документация и локальные коммиты** после каждого блока.

## 4. Правила экспериментов и приёмки

- Для каждого эксперимента фиксируем: гипотезу, конфиг, прогон (`artifacts/eval/...`), метрики на
  `real_v1`, `synth_v2`, `loo`, задержку p50 / p95.
- **Принять**, если top-1 на `real_v1` не падает и растёт хотя бы одна из: top-1 на `real_v1`,
  top-1 на сериях, open-set top-1; и p95 ≤ 3 с на RTX 3090.
- Веса и пороги подбирать на одной части валидации, проверять на другой (как seed 0 / seed 1 у
  детектора); `real_v1` не использовать для подбора большого числа параметров — только проверка
  и финальная калибровка.
- Результаты — в `docs/RESULTS.md` (генерируется) и запись в WORKLOG.

## 6. Чего не делаем и почему

| Не делаем | Почему |
|---|---|
| YOLO26 / YOLOE / YOLO-World как основа | AGPL / GPL (барьер для внедрения в РСХБ) |
| SuperPoint, MASt3R | некоммерческие лицензии |
| SAM 3, Florence-2, DINO-X | тяжёлые или только облачный API, нет выигрыша для нашего кейса |
| Alpha-QE, k-reciprocal, диффузия на графе | нет подтверждений при одном эталоне; соседи — вина той же серии |
| Генерация ракурсов диффузионными моделями | искажают текст этикетки |
| GOT-OCR, InternVL2, Surya | слабый русский на сценах / лицензия |
| LLM-сомелье «из головы» | галлюцинации позиций 11–61%, сочетания с едой — худшая область LLM |

## 7. Вопросы, от которых зависит план

1. **Сроки** промежуточной и финальной сдачи — выбрать маршрут А или А + Б.
2. **Можно ли снять реальные фото** (этап 0.1) — без этого точность подтверждается только синтетикой.
3. **Доступ к LLM:** разрешить запросы к предоставленному шлюзу или использовать GigaChat /
   YandexGPT / локальную Qwen для сомелье и VLM.
4. **Проверка на CPU или GPU** у экспертов — влияет на выбор VLM и ансамблей.
