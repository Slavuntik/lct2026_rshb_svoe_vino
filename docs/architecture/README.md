# Архитектурная документация — «Свой Сомелье»

Пакет собран к сдаче кейса ЛЦТ 2026 (задача тимлида 22.09, решение Вячеслава) — критерий
«Архитектура (разделение, воспроизводимость)» весит 15/100 (`case.md` строки 79–87). Пять
файлов, у каждого один автор и одна зона — читаются вместе, не дублируют друг друга.
Корневой `ARCHITECTURE.md` — краткий вход в один экран, ссылается сюда за подробностями.

## Как читать

**Жюри/новый человек в проекте, 10 минут:** `../../ARCHITECTURE.md` (корень, один экран) →
`HLD.md` §1–2 (контекст, зачем именно так) → `HLD.md` §7 (ADR-таблица — самое плотное место
по решениям).

**Хочу понять, почему сканер отвечает именно так на КОНКРЕТНОМ фото:**
`models-and-algorithms.md` §2 (алгоритмы) → §4 (что отвергли и почему — если решение выглядит
странно, скорее всего альтернатива уже пробована и не сработала) → `LLD.md` §3.1–3.3
(sequence на уровне HTTP-запроса, не только формул).

**Хочу подключиться к разработке чата/гастропар:** `lld-rag-chat-pairing.md` целиком (он
самодостаточен для этой части) → `LLD.md` §3.4–3.6 (как эта часть стыкуется с остальной
системой) → `contracts/{rag-interface,llm-adapter,post-scan}.md` (контракты, если меняете
поведение).

**Разворачиваю/чиню стенд:** `operations.md` целиком (самодостаточен) → `HLD.md` §5
(архитектурный смысл топологии, если непонятно «почему так») → `HLD.md` §8 (риски —
проверить, не наступаете ли на уже известный).

**Ищу конкретный факт (порог, env-переменную, число точности):** сначала грепом по всем пяти
файлам — у каждого факта один хозяин, дубликатов быть не должно; если факт не находится ни в
одном — это пробел документации, не факт «его нигде нет» (сверить с `reports/`/`contracts/`
напрямую).

## Кто что правит

Контракты (`contracts/*`) — только architect, отдельно от этого пакета. Каждый файл документации
выше — правит только автор из таблицы; остальные ссылаются, не редактируют чужую зону (тот же
принцип write-зон, что `TEAM.md`). Расхождения между файлами (если найдены) — фиксируются как
явная находка с датой в том файле, где обнаружены, не молча правятся в чужом.
