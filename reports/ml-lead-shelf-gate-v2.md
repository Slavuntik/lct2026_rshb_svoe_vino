# ml-lead: гейт «кадр полки» v2 — доп. сигнал против одиночной бутылки (22.09)

Офлайн (без живого API, Mac свободен). Код `cv.shelf_crop` (коммит 8459f57) НЕ правил — только
импортировал в новый прототип `qa/real_photos_shelf_gate_v2.py` (`--diagnose` детектирует боксы
+ считает геометрию поверх боевого `segment_boxes(gate=False)`; `--sweep` печатает таблицу;
`--target8` — разбивку по 8 целевым полевым; `--show <файл>` — диагностику одного фото).

## Данные

100 фото организаторов (`case-data/real-photos`, ВСЕ — 62 в каталоге + 38 NONE), 32 полевых
(`Field/`, ВСЕ), 25 «настоящих полок» = qa-manual confidence sure+likely (26 строк
`part3-field.csv`) минус 1 побайтный дубль (F17=F16 по md5) — воспроизвёл ровно число тимлида
(`real_shelves_25()`).

## Сигналы (геометрия поверх уже выбранного v1 ряда/колонок, доп. модель не нужна)

| сигнал/порог | 100 орг. (цель 0) | 32 полевых | 25 полок |
|---|---|---|---|
| только v1 (колонки≥2 И боксов в ряду≥30) | **4** | 17 | 15 |
| A: доля ширины центр. колонки < 0.30 | 1 | 12 | 12 |
| A: < 0.50 | 3 | 15 | 14 |

Только **D** (аспект текстового кластера ряда — независим от того, на сколько колонок его потом
разрезали) даёт 0/100 с запасом: максимум среди 4 ложных срабатываний v1 — 1.106, порог 1.2 —
запас 0.09, посчитан на ВСЕХ 100, не подогнан под конкретный кейс. A/B/C поодиночке 0 не дают
(1-3/100 остаются) — таблица показывает почему честно, не только лучший вариант.

## Регрессия ML-2 и 8 целевых полевых

`87.88_28-08-2026_16-56-20.webp` (живая регрессия ML-2, `reports/ml-eng-ml2.md`, 95.2%→93.5%) —
text_aspect=1.06 < 1.2, **гейтом v2 исключается**. Из 8 целевых полевых (`part3-field.csv`,
sure/likely, вино в каталоге) сигнал D теряет только F04 (живьём чистый минус, ранг 3→нет) и F08
(живьём нейтрален, both=1) — остаются F02/F10/F16/F17/F21/F30 = **6/8**, выше бара приёмки (≥2/8).

## Решение

Сигнал найден, не подогнан под 62/8/регрессию (порог — максимум ложных срабатываний на ВСЕХ 100,
правило объяснимо) → бриф `agents/ML-3-shelf-gate.md` для ml-engineer: добавить `text_aspect` в
`is_shelf` (`cv.shelf_crop.segment_boxes`), конфиг `CV_SHELF_MIN_TEXT_ASPECT=1.2`, живая приёмка
по критерию тимлида (62 фото — 0 регрессий, 22 NONE — 0 новых ложно-уверенных, полевые ≥ 2/8).

## Как воспроизвести

`packages/cv/.venv/bin/python qa/real_photos_shelf_gate_v2.py --diagnose` (36 с, кэш →
`qa/scan-eval-runs/shelf-gate-v2/{organizer,field}_diag.json`), затем `--sweep --target8`
(таблица выше + разбивка по именным фото).

## Риски / предложения

1. Запас 0.09 над макс. ложным срабатыванием посчитан на ЭТИХ 100+32 фото офлайн — живое/офлайн
   расхождение в проекте уже 3 раза (ORCHESTRATION.md, ml-lead-plan.md) — обязательна
   перепроверка на живом API, не брать 1.2 как готовое число без сверки.
2. Recall на полевых честно падает (17→12/32, 15→10/25 «полок») — v2 жертвует частью полезных
   срабатываний ради нуля ложных; более мягкого варианта без роста FP>0 не нашёл. Комбинации
   сигналов (D + A/B/C) не проверял — D одного хватило для цели задания.
