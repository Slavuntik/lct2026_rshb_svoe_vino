- Противоречий по лицензии в репозитории **нет**: `MIT`/`SPDX-License-Identifier` в наших
  манифестах, заголовках файлов и docs — 0 вхождений. 9 `package.json`: 8 с `private: true`
  без поля license, 1 (`apps/shell/plugins/ocr-plugin`) с `"license": "UNLICENSED"` — это
  npm-канон для проприетарного, оставлено. 7 `pyproject.toml` — поля license нет ни в одном.
- Лицензии зависимостей сверены по `*.dist-info/METADATA` установленных версий (20 пакетов) и по
  реестру моделей `fastembed 0.8.0`, не по памяти.
- **Три ограничивающих пункта** выявлены при сверке лицензий:
  - `jinaai/jina-reranker-v2-base-multilingual` — **cc-by-nc-4.0** (подтверждено кодом:
    `fastembed/rerank/cross_encoder/onnx_text_cross_encoder.py:60`); выключается пустым
    `RAG_RERANKER_MODEL`, поиск продолжает работать на RRF;
