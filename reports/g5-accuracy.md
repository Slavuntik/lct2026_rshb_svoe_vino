`qa/accuracy_lab.py` — офлайн поверх packages/cv (ImageIndex+LabelVerifier, без HTTP),
case-synth-honest (2054 фото, сплит scan_eval.py: dev=1680/holdout=374). `cv/text_rerank.py`
— IDF-пересечение + rapidfuzz, транслитерация кириллица↔латиница в общий алфавит,
**безопасный гейт** `min_token_idf` (медиана IDF каталога): OCR без различающего токена ==
пустой OCR (порядок CV не меняется) — без гейта ~30% "непустого мусора" синтетики
регрессировали full-dev уже при w=0.01 (найдено 21.09, закреплено тестами гейта).

## Синтетика занижает пользу OCR (поправка оркестратора 21.09)
`ocr_yield`: доля фото с ≥1 различающим токеном — синтетика 3.4% vs **реальные бутылки
33.3%** (3 eval/queries + 3 скана стенда, case-data/stand-scans) — 10x разрыв (мелкие
эталоны + аугментация рвут мелкий текст). Полки (field-shots, стресс) — 0% информативных,
0/7 правок топ-5. Вывод: CV/TTA-цифры на синтетике надёжны; OCR-rerank синтетика меряет
КОНСЕРВАТИВНО — решение по w опирается на доказанную безопасность + реальные фото, не
только на holdout выше.
