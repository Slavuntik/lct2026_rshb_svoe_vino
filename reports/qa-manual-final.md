## Что понравилось бы жюри
- Возраст: «Нет» → «Извините, доступ только для совершеннолетних», флаг в хранилище не ставится.
- Скан уверенного фото → «Рубин Голодриги · Табия · Кубань», ссылка `vino-svoe.ru/wines/rubin-golodrigi`
  (проверил: 200, `target=_blank`, `rel=noopener`). Близнецы по сахару: Жемчужная 9 полусладкое →
  слаг `…-muskat-rozovyj-2`, ровно как на этикетке (три near-dup SKU отличаются только сахаром).
- «Покажите нужную бутылку»: рамка с уголками поверх фото, повторный поиск по рамке — тот же ответ.
- Сомелье: кнопка из карточки подставляет вопрос про это вино; ответ по делу, цитаты ведут ВНУТРЬ
  (`/app/wine/<slug>`), не наружу. Не по теме («как поменять масло») → «Честно: не нашли достаточно
  надёжных источников» — ровно та честность, которую обещает лендинг.
- «Аналог импортного»: Кьянти → «Похоже на стиль «Кьянти Классико» (Италия)» → 8+ российских
  Санджовезе с винодельнями и регионами, клик ведёт в карточку.
- Фото бутылки в режиме «Блюдо» → «Это похоже на бутылку вина, а не на блюдо» + кнопка-мостик.
- Профиль: согласия, выгрузка JSON, удаление аккаунта — сильная privacy-история.
- 375 px: `scrollWidth === clientWidth === 375` на лендинге, скане, карточке, чате, профиле и юр-страницах.
- `/v1/docs` — Swagger с разделом «Авторизация» и ссылками на контракты; `/v1/metrics/scan` свежий.

## Как воспроизвести
Пустые шкалы: открыть `/app/wine/rubin-golodrigi` →
`getComputedStyle(document.querySelector('.taste-axis__fill')).display` = `inline` (ожидалось `block`).
Провал «Похоже по вкусу»: `POST /v1/analogs {"query":"Красностоп Золотовский"}` → 404 `not_found`.
Скриншоты снимались playwright-скриптом из `qa/.venv` по тем же URL, гостевым входом, только чтение.
