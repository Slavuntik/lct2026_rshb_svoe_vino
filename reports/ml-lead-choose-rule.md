# ml-lead: офлайн-проверка CV_FUSION_CHOOSE (22.09)
`qa/real_photos_choose_rule.py` — только `features/`+кэши, живой API не поднимал.
Формула — боевая `cv.text_fusion.fuse()` (не переизобретена): `cv+0.3·rel`, гейт
винодельни, штраф цвета 0.05; CV — индекс `base384_d1` (cv_index_version стенда),
кандидаты CV top-50 ∪ точный CV-скор текстовых top-30 (мимикрия `search_fusion`, не approx).

## Сверка формулы (до экспериментов)
Без `case-data/winery_aliases.json` (как сейчас НА СТЕНДЕ — не скопирован,
`reports/ml-eng-ml1.md`): **local(CV+OCR) 59/62=95.2%, model(CV+27B) 59/62=95.2%,
merge 60/62=96.8%** — бит-в-бит `reports/devops-stand-vlm.md`. С алиасом (как в
`case-data/` сейчас; гейт бьёт только `text_source="ocr"`) local тоже 60/62=96.8%
(чинит Голубицкое), model/merge не меняются (гейт для vlm-источника без эффекта).
Формула подтверждена; таблица ниже — алиас ВКЛ (текущие признаки).

## Правила, 62 фото чисто, и потеря при галлюцинации модели (Δ фото, 10→30→100%)
| правило | точность | shuffle | niche (похожая ниша) |
|---|---|---|---|
| merge (бой) | 60/62 = 96.8% | −3/−6/−17 | −2/−6/−16 |
| max_score | 59/62 = 95.2% — хуже merge | −1/−3/−5 | −2/−1/−7 |
| agree_else_llm | 59/62 = 95.2% — хуже merge | −6/−18/−57 | −5/−16/−47 |
| agree_else_cv | 60/62 = 96.8% | **0/0/0** | **0/0/0** |
| confident_else_cv (своё) | 60/62 = 96.8% | −1/−6/−10 | −1/−2/−11 |

Матфакт (не гипотеза): `agree_else_llm` тождественно `model` по топ-1 на КАЖДОМ фото,
`agree_else_cv` тождественно `local` — ветка "agree" неотличима от одной из веток
"else" (f=g ⟹ h:=f/g тождественны). Реально независимых стратегий пять: merge, local,
model, max_score, confident_else_cv.
`confident_else_cv` (своё, с порогом): доверяем модели, только если её fuse()-результат
сам проходит СУЩЕСТВУЮЩИЙ гейт `result.confident` (gap≥0.03 и cv_score≥0.80 —
откалиброван отдельно, не под эти 62 фото), иначе локальный. На обеих подменах чтения
(перестановка между фото; чтение бутылки той же категории+сахара, донор находился
всегда) — на каждой точке 10/30/100% лучше-или-равно merge, не хуже merge на чистых.
`agree_else_cv` устойчивее (структурный ноль потерь), но без алиаса на чистых уже
95.2% — хуже merge, целиком выбрасывая модель.

## Модель мертва и 38 фото без вина в каталоге
Все 5 правил дают ПОБИТОВО ответ = local (95.2%/96.8%) при пустом vlm-тексте на всех
62 — явная проверка "не ответила ⇒ local" в `decide()` для всех, кроме merge (сам
сводится к local тем же вызовом `fuse()`). Смена топ-1 на 38 NONE-фото относительно
merge: max_score 2/38, agree_else_llm 1/38, agree_else_cv/confident_else_cv 11/38.

## Рекомендация тимлиду
**`CV_FUSION_CHOOSE=confident_else_cv`** — на чистых 62 не хуже merge (60/62, в обоих
состояниях алиаса); при 10–100% галлюцинаций теряет заметно меньше merge на каждой
проверенной точке (10%: −1 фото против −3 у merge), используя уже откалиброванный, не
подогнанный под выборку порог. Максимально защищённая альтернатива ценой отказа от
апсайда модели — `agree_else_cv`. `max_score`/`agree_else_llm` хуже merge уже на
чистых — отклоняются правилом тимлида.
