# backend — «Похоже по вкусу» на автохтонах: честный пустой результат (27.09)

Находка: `reports/qa-manual-final.md` #4 (P2, видна жюри). Зона: `apps/api/app/routers/analogs.py`,
`apps/api/tests/test_analogs.py`. Контракты/фронт не трогал (правки — предложения ниже).

## Причина

`POST /v1/analogs` обслуживает две сцены: «аналог импортного» (ChatScreen, текст в поле) и «Похоже
по вкусу» (ScanScreen `resolveTasteAnalogs` — вызывается АВТОМАТИЧЕСКИ сортом уже открытой карточки,
без поля ввода). Для Рубина Голодриги / Красностопа Золотовского / Цимлянского чёрного
`retriever.resolve_style(grape)` честно не находит иностранный стиль (у автохтонов его и не должно
быть) → роутер бросал `ApiError(404, "not_found", "Не удалось распознать стиль по описанию.
Популярные стили: <топ-5 из REFERENCE_STYLES>")`. Оба места фронта (`ScanScreen.tsx:461`,
`ChatScreen.tsx:206`) на ошибке печатают `error.message` буквально — отсюда «сырой 404 текст +
иностранные стили» на карточке российского вина. Каберне/Рислинг/Саперави резолвятся напрямую → 200.

## Что сделано

`_NOT_FOUND_MESSAGE = "Честно: похожих по стилю иностранных вин не нашли."` — без «ошибка»/«не
удалось» и без имён внутренних стилей (voice уже в проекте: `notInCatalogMessage`, чатовское
«Честно: не нашли достаточно надёжных источников»). `list_reference_styles(top_n=5)` пользователю
больше не идёт — переведён в `logger.info` (отладка словаря, не PII). Фронт трогать не пришлось.

Код/статус **оставлены 404 `not_found`**, а не 200 — несмотря на «пустой результат, а не ошибка» из
задачи. Оба вызывающих (`ScanScreen.tsx`: `TasteAnalogsState.status:"ready"` требует `style:
AnalogStyle`, не `|null`; `ChatScreen.tsx`: `result.style.slug` без проверки) на успехе (200) читают
`response.style.slug` безусловно — `style: null` уронил бы там необработанный `TypeError`, пойманный
`.catch()` как ОБЩИЙ `common.errorGeneric`, хуже нынешнего честного текста. Фронт занят другим
агентом — 200 без правки там не безопасен; 404 также сохраняет ретрай ScanScreen по первому сорту
купажа (>1 сорт).

## Предложения к контрактам (architect)

`contracts/openapi.yaml` `/analogs`: `"404": {description: ...в message топ-5 поддерживаемых}` →
`...message — честная формулировка БЕЗ перечисления внутренних стилей`; в описании метода убрать
«с подсказкой популярных стилей». Не срочно: в следующей ревизии рассмотреть `style: null` + 200,
но только вместе с правкой фронта (снять инвариант «200 ⟹ style не null» в обоих экранах) — иначе
регрессия, см. выше.
