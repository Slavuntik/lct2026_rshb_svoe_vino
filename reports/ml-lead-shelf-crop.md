# ml-lead: локализация бутылки на кадре ЦЕЛОЙ ПОЛКИ (22.09)

Офлайн, без живого API (Mac занят приёмкой ml-engineer). Новый скрипт
`qa/real_photos_shelf_crop.py` (прототип по образцу `qa/real_photos_label_crops.py`).

## Метод

Шаг 0 перед стандартным конвейером: (1) детектор текста RapidOCR (сенситивный, детекция без
распознавания) по всему кадру; (2) РЯД (полка) — растим окно от Y-центра кадра наружу по сильно
сглаженной плотности боксов до структурного разрыва между полками (жёсткое разбиение на N рядов
порогом пробовал первым — ломается, разрыв внутри ряда типа этикетка/ценник не мельче разрыва
между полками); (3) КОЛОНКИ (бутылки) внутри ряда — реальные разрывы нулевого X-покрытия, фолбэк
— проекция границ Sobel/OpenCV при < 2 колонок; (4) раздел Вороного между колонками = кроп «одна
бутылка с полями», ближайшая к X-центру = «центральная». Дальше стандартный конвейер на кропе (2
эмбеддинга CV + RapidOCR 640/960 сенситивный), слияние W=0.3/α=0.5 как в `real_photos_cpu_path.py`.

**Гейт «это полка»** (иначе п.2-4 портят студийные фото каталога): колонок ≥ 2 И боксов в ряду
≥ 30 — порог измерен, не из головы (ниже).

## Как воспроизвести

Из `packages/cv`: `.venv/bin/python ../../qa/real_photos_shelf_crop.py --dump-field` (без
CV_MODEL); `CV_MODEL=google/siglip2-base-patch16-384 .venv/bin/python
../../qa/real_photos_shelf_crop.py --eval-field` (35 с) / `--eval-organizer` (55 с) /
`--eval-organizer --always` (71 с). `SHELF_MIN_BOXES=N` — переопределить порог.

## Риски / предложения

1. Фолбэк не разделяет плотные ряды ИДЕНТИЧНЫХ бутылок (F02: 10→3 «колонки») — вне бюджета.
2. Граница Вороного — без нахлёста; 2/8 промахов ровно на границе. Дешёвый неизмеренный
   follow-up: топ-1 и по соседним колонкам, брать лучший по тексту — на усмотрение ml-engineer.
3. Сжатые WhatsApp-фото (960×1280) при дроблении на 4-5 колонок дают ~200px/бутылку, доп. кроп
   текст не восстанавливает (та же находка qa-manual, `reports/qa-manual-field-photos.md`).
   Нет предложений к `contracts/image-scan.md` — офлайн-гейт (cv≥0.80/gap≥0.03) мой прокси для
   этой задачи, не боевые `CV_ABS_FLOOR`/`CV_MARGIN_FLOOR` (0.82/0.02) — приёмка меряет живым.

Результат положительный (доля, без регрессии) → бриф `agents/ML-2-shelf-crop.md`.
