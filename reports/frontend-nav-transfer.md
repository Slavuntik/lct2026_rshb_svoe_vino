Шапка с маркой/поиском/сэндвич-меню из `design/ui-prototype`, меню со всеми разделами +
условная «Витрина», решение по нижней панели. Живой прототип (5199/3001) не трогал — вся
разметка/CSS взяты из `design/ui-prototype/web/src/{App.tsx,styles.css}`.

## Сделано

- Марка: лого кейса скопировано статикой `design/ui-prototype/assets/logos/svoe-vino.svg` →
  `apps/web/public/brand/logo-svoe-vino.svg` (код на папку прототипа не ссылается). Решение по
  бренду тимлид менял дважды по ходу — см. «Флаги» п.1.
- Шапка `apps/web/src/app/nav/TopHeader.tsx`: скруглённая плашка, марка слева (ссылка на
  `/app/scan`), поиск + сэндвич справа, sticky, `max-width:720px` как у `.container`. Сверил
  живьём с макетом Figma «РСХБ вино» (прислан тимлидом по ходу задачи, экран «каталог вин»,
  Properties-панель): паддинг пилюли поправлен на точные 14/16/14/16 и убрана рамка (в
  макете её нет) — совпало 1-в-1 с тем, что уже было построено по прототипу.
- Меню `apps/web/src/app/nav/NavMenu.tsx` + `useFocusTrap.ts`: монтируется только пока открыто
  (это и есть анимация — CSS `@keyframes`, не JS-таймер). Esc и клик по подложке закрывают;
  фокус на кнопку закрытия при открытии, на триггер при любом закрытии; Tab/Shift+Tab не
  выходят за пределы панели. `prefers-reduced-motion` — `lib/motion.ts` (`matchMedia`, без
  падения при отсутствии API), `animation:none`, тестируемо мокой. Пункты: Скан, (Витрина —
  только `shelfAvailable`, проп из готового `useShelfAvailability`, логику не трогал),
  Сомелье, Вкус, Профиль; юр-ссылки внизу (ключи `landing.legal*Link`, файлы не редактировал).
- Поиск: иконка → `navigate("/app/scan#scan-text-search")`; `ScanScreen.tsx` слушает
  `location.hash`/`location.key`, фокусирует существующую textarea текстового поиска.
- Нижняя панель вкладок **удалена** → (а) сэндвич-меню как единственная полная навигация,
  (б) плавающий ярлык `ScanShortcut` (не рендерится на `/app/scan`) — ускоритель одного
  действия, не вторая навигация. До Скана — 1 тап (ярлык), до Сомелье — 2 (меню→пункт);
  конкурирующих полных навигаций на экране нет.

## Флаги тимлиду (не блокировали работу)

1. **Бренд-марка**: исходный бриф прямо запрещал лого РСХБ («чужой бренд»); сегодняшний
   `reports/frontend-design-transfer.md` уже осознанно отказался от него по той же причине.
   Две правки тимлида (включить лого+дисклеймер → убрать дисклеймер) выполнил как есть
   (лого без дисклеймера). Фиксирую расхождение с исходным брифом письменно.
2. **Полный перенос оформления (шрифты/палитра/все экраны, включая юр-страницы) — не делал.**
   Пришедшее следом сообщение об этом — другая по масштабу задача, вопреки сегодняшнему же
   решению `frontend-design-transfer.md` и явному «не трогай юр-страницы» в моём брифе, за 2
   дня до сдачи, без отдельного ревью. `tokens.css` и другие экраны не менял.
3. **Фон юр-страниц ≠ фон приложения** — находка верная (`legal.css` жёстко `#FBF9F7`), но
   просят подогнать под **portal**-тему (`#FDF9ED`), которую я не включал (п.2). Если на
   стенде стоит `VITE_THEME=portal` — это конфигурация devops, чинить синхронизацией токенов,
   а не разовой подгонкой. Юр-страницы не редактировал (явное «не трогай»); нужен отдельный
   бриф (architect/product — меняется общий источник токенов).
4. **Ссылка на Figma-макет** (пришла в ходе задачи) открыл в браузере Вячеслава
   (`claude-in-chrome`, только просмотр, вкладку закрыл после) — использовал ТОЛЬКО для
   сверки шапки (п. «Сделано» выше, см. цифры). Заметку «валя, прочитай это» на холсте
   прочитал: это продуктовое видение сканера (антипаттерн Vivino, одна уверенная карточка,
   retention-фичи, JSON-формат под скрипт оргов) — контекст, не новые команды, содержательно
   совпадает с тем, что уже есть в `TEAM.md`/`ORCHESTRATION.md`. Полный обход всех макетов и
   сверку остальных экранов не делал — это и есть задача из п.2, тем же макетом её не сузить.
