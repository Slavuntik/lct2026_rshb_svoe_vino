# Frontend — остальные экраны в дизайн-системе (27.09)

Задача тимлида: перенести дизайн-систему карточки вина (`WineCardContent.tsx`/`.card`/`.spec-tiles`/`.chip`)
на онбординг, профиль, паспорт вкуса, чат-сомелье, метрики, «Витрина недоступна», сканер — по
конкретным дефектам, увиденным тимлидом живьём на 375px (`http://localhost:5176`, режим real).
Правки только `apps/web/`. Не трогал (по прямому запрету, доделывает другой агент): `WineCardContent.tsx`,
`ScanShortcut.tsx`, блоки `.spec-tile*`/`.scan-shortcut` в `global.css` — на момент старта эти файлы
уже были закоммичены чисто (`70a9c98`), конфликтов не было.

## По экранам

- **Профиль**: 5 заголовков → `.card-heading` (Согласия/Вы-гость/Выгрузка/Удаление/модалка «Точно удалить?»); бейдж «Гостевой доступ» не растянут; чекбоксы; кнопки уже были 3 осознанные роли (primary/secondary/danger) — не трогал код ролей, только исправил их `:disabled`-состояние глобально.
- **Паспорт вкуса**: `.card-heading` на «Пока вы — гость»/«Нужно согласие»/«Вина закончились»/«Ваш вкусовой вектор». Название вина на карточке свайпа (`currentWine.name`) **не трогал** — это герой-контент карточки (как заголовок товара), не секция настроек; рядом нет других 32px-заголовков на этом экране, конфликта нет.
- **Чат**: чипы/плейсхолдеры/линия/disabled-кнопка — см. таблицу. `<h2>` на этом экране нет вовсе (проверил кодом) — пункт задания «применить в чате» технически покрыт понижением уровня `.chip`/убиранием линии; заголовков к понижению не нашлось.
- **Метрики**: плитки + `<details>`. Заголовков `<h2>` на этом экране не было изначально.
- **Витрина недоступна**: см. таблицу.
- **Онбординг**: разделитель, `.card-heading` на «Согласия», чекбоксы, `color-scheme`. Радиус/палитра поля даты уже были верны (`--radius-sm`, `--card`, `--ink` — проверено computed style), реальная проблема — низкая видимость плейсхолдера/иконки календаря нативного виджета, чинится тем же `color-scheme`.
- **Сканер**: дропзона и поле «Текст с этикетки» уже соответствуют системе (радиус 20/14, палитра, пунктир дропзоны — осознанное исключение для аффорданса drag&drop, в макете этой рамки нет вовсе); поменял только роль кнопки «Найти вино» на secondary.

## Намеренно НЕ менял

1. `WineCardContent.tsx`, `ScanShortcut.tsx`, `.spec-tile*`/`.scan-shortcut` — прямой запрет (другой агент).
2. `SomelierCardWidget.tsx` («Цифровой сомелье», h2=32px) — файл не запрещён, но его заголовок стоит
   в потоке карточки вина/скана РЯДОМ с «Вкусовой профиль»/«К чему подать» (оба живут в запрещённом
   `WineCardContent.tsx` и остаются 32px) — уменьшить один из трёх соседних заголовков было бы НОВОЙ
   рассогласованностью, не починкой старой. Живьём проверил (`/app/wine/<slug>`) — все три сейчас
   визуально одного размера.
3. Заголовки внутри результатов `ScanScreen.tsx` (Похожие/Аналоги/«Похоже по вкусу» и т.д.) — не
   входят в явно названные 4 экрана задания (профиль/паспорт/чат/метрики); скану отдельно перечислены
   только дропзона/текстовое поле/кнопка.
4. `button.icon-badge:disabled` (кнопка-иконка отправки в `SomelierCardWidget`) — тот же приём
   opacity, что чинил у `.btn`, но это иконка, не текст; в задании явно назван текстовый пример
   («Спросить» в чате). Не трогал, чтобы не расширять правку за пределы текстовых кнопок без запроса.
5. Тап-зона `.chip` (~29px, ниже 44px) — тот же контрол уже везде (режимы скана, вопрос/аналог) до
   этой волны; правка задела бы общий примитив по всему приложению без отдельного запроса — фиксирую
   находку тимлиду ниже.
6. Текст `metrics.eval_set`/`index_version`/бейджи каталога — данные, не интерфейсные тексты, не менял.

## Риски и предложения

1. **Шапка-пилюля**: не смог воспроизвести течь статикой в Chromium (программный зонд под шапкой
   на всю область — не виден ни разу; сама `.app-header` подтверждённо на 100% ширины и непрозрачна).
   Похоже на транзиентный компоузинг-баг sticky-элементов при скролле (частый класс на Safari/iOS) —
   применил стандартный фикс (`isolation`+`translateZ`+`will-change`), но **нужна повторная живая
   проверка тимлидом на том же устройстве/браузере**, где баг был замечен изначально.
2. `.chip` тап-зона ~29px < 44px — системная, не только моя правка «Фильтры»; если важно для итоговой
   сдачи, отдельная небольшая волна на `global.css` `.chip`.
3. `button.icon-badge:disabled` (виджет сомелье) — тот же класс дефекта, что был у `.btn:disabled`,
   не тронут (иконка, не текст, вне явного примера задания) — можно взять отдельным тикетом.
4. `SomelierCardWidget.tsx` h2=32px остаётся рассогласован с новым `.card-heading`, если/когда
   WineCardContent.tsx выйдет из-под правок другого агента — стоит решить единым заходом с
   «Вкусовой профиль»/«К чему подать», не по одному виджету.

Коммит: `apps/web` + этот отчёт, pathspec отдельно, без push.
