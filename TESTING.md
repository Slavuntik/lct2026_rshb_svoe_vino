# Проверка «Свой Сомелье» — Digital Rover

## Прогнать папку через основной детектор

Из корня репозитория, при работающем настоящем API:

```bash
python3 tools/eval_detector.py \
  --images-dir /path/to/photos \
  --endpoint http://84.201.163.74/v1/eval/predict \
  --output ./eval-results/predictions.jsonl
```

Рекурсивный обход, один запрос на фото, без повторов. Создаются `predictions.jsonl` и `predictions.report.json`; результаты не публикуются в Git, папка `eval-results/` исключена через `.gitignore`. Для локального Docker API замените адрес на `http://127.0.0.1:8080/v1/eval/predict`; для `scripts/quickstart.sh` порт по умолчанию 8000.

## Проверка набором организатора

```bash
python3 tools/eval_detector.py \
  --dataset /path/to/unpacked-eval \
  --endpoint http://127.0.0.1:8080/v1/eval/predict \
  --output ./eval-results/official.jsonl \
  --report ./eval-results/official.report.json
```

Ожидаются `queries.tsv` и `queries/`; при наличии `checksums.sha256` он проверяется. Оригинальный `eval/participant_test.sh` не изменяется. Для будущего набора от 1 октября требуется повторить эту проверку после его получения.

## Проверить саму утилиту

```bash
python3 -m unittest discover -s tools -p test_eval_detector.py
```

15 тестов, локальный HTTP-сервер и настоящий shell-скрипт организатора; внешние модели не нужны. Проверка включена в CI как `eval-tool-tests`. Обязательны Bash, curl, jq, awk, sha256sum/shasum и Python 3.11+.

Основной каталог — 2103 вина. Утилита ищет по полному загруженному индексу сервера, не по тестовой папке и не по top-5 заранее выбранных вин. Покрытие фотоэталонами описано в [инструкции](docs/EVAL_DEMO.md).

## Прочитать результаты

- Код `0`: все строки валидны и содержат slug; это не доказательство точности.
- Код `2` после прогона: результаты сохранены, есть `null`; изучите фото и логи API. При ошибке аргументов CLI тот же код может вернуться до прогона без файла.
- Код `1`: ошибка окружения, сервиса, скрипта или данных.
- Код `130`: прерывание; полного отчёта может не быть.

Для точности нужна отдельная эталонная разметка. На нашем архиве 119 фото проведена такая сверка: 70/72 известных вин, один пустой ответ на фото здания без бутылки. Подробности, файлы, параметры CLI и ограничения — в [инструкции оценки](docs/EVAL_DEMO.md).
