## Смысловой итог волны

1. **Гейт ожил**: match-rate 6.8% → **41.6%** на тех же 1982 фото; raw top-1
   стабилен 69.4% (гейт не трогает ранжирование — sanity). Цепочка причин:
   null-gap-семантика → пропуск near-dup роутинга при null → кандидаты «по семье»
   вместо «по близости» → пороги старой шкалы. Четыре дефекта, четыре фикса,
   каждый запинен тестом.
2. **q2 «Мускатель Массандра» закрыт e2e**: верный слаг, ocr_verified=true —
   верификатор читает этикетку и переставляет внутри визуальной семьи. Ключ —
   метаданные кандидатов из каталога КЕЙСА (наш каталог кейс-слагов не знает).
3. **Идея Вячеслава «иностранное → российский аналог» реализована** (/scan/resolve:
   токены сорта/стиля из pipeline/ref → общий резолвер с /analogs). Живьём:
   «Urban Risling» → рислинги Абрау-Дюрсо/Юцис/АРАТТИ/Бельбек. Попутно убит баг
   индекса стилей («вино» матчилось на всё).
4. **Реальный RAG вскрыл латентные 500-ки** ветки аналогов (94 вина с пустыми
   winery/name/region) — схема сделана честной (Optional / отброс безымянных),
   финальный прогон и ручная проверка пары талю: 0 ошибок.
5. Прогревы: первый запрос 2.1 c → **137 мс** (истинная причина была в ленивом
   первом search embedded-qdrant, не в PaddleOCR — находка B4).

## Процесс

- Ловушка «отвязанный фон не будит агента» поймала четверых (G3 ×3, G4, B3-поллер,
  B6) — правило в ORCHESTRATION.md работает, но нуждается в напоминании в КАЖДОМ
  брифе. Шаблон завершения через «оркестратор перезапускает стенд, агент бьёт по
  нему HTTP» (B6/B7) показал себя лучшим — закрепляем как норму для e2e.
- B5 и B3 дали образец поведения: проверка приказа оркестратора до исполнения
  (ложная тревога «API на моке» опровергнута уликами). Поощряется.
- Мой методологический промах: приёмка B4 шла на грязном дереве с некоммиченными
  правками G4 — цифры before/after оказались несравнимы. Норма: приёмочные прогоны
  только на закоммиченном дереве.
