# WineScan — сканер российских вин по фото этикетки

Решение кейса РСХБ «Сканер российских вин с описанием на платформе „Своё вино“»
(«Лидеры цифровой трансформации 2026»). Пользователь фотографирует бутылку у полки,
сервис возвращает **одну** карточку вина из каталога «Своё вино». Техническое задание —
[`10. РСХБ.Цифра.pdf`](10.%20РСХБ.Цифра.pdf).

| Документ | О чём |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | пайплайн, границы слоёв, контракты, принятые решения |
| [docs/DATA.md](docs/DATA.md) | что лежит в данных кейса, найденные особенности и ошибки данных |

| Слой (см. ARCHITECTURE.md) | Состояние |
|---|---|

## Структура репозитория

```
10. РСХБ.Цифра.pdf          ТЗ кейса
configs/
  photo_overrides.csv       ручные решения «вино -> файл эталона» (с причинами)

docs/                       DATA.md, WORKLOG.md
scripts/
  extract_dump.sh           распаковка RAR-дампа Strapi
src/winescan/
  config.py                 пути, переопределяемые переменными окружения
  catalog/                  слой 0: данные каталога
    loader.py               чтение и очистка CSV
    attributes.py           год / сладость / игристое / объём из названия и slug
    strapi_names.py         правила имён файлов Strapi Upload
    images.py               размеры, прозрачность, sha256, pHash, «студийность»
    matching.py             привязка фото из CSV к файлам uploads
    review.py               контактные листы для ручной проверки
    report.py               markdown-отчёт сборки
    build.py                CLI сборки каталога
tests/                      pytest
artifacts/                  результаты сборок, в git не кладутся
```

## Требования

- Linux (проверено на Ubuntu 24.04), Python 3.12.
- `unrar` с поддержкой RAR5: `sudo apt-get install unrar` (репозиторий multiverse).
  Установленный в Ubuntu `7z` (7zip 23.01) без плагина `7zip-rar` **не подходит**:
  на сжатых записях пишет `Unsupported Method` и оставляет пустые файлы.
- ~2,5 ГБ диска под распакованный дамп, ~20 МБ под артефакты каталога.
- GPU для слоя 0 не нужен.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
```

## Данные

Положить выданные файлы в `data/`:

```
data/strapi_output0709.csv
data/prod-svoe-vino-strapi.part1.rar  part2.rar  part3.rar
data/eval.zip
```

Распаковать:

```bash
scripts/extract_dump.sh      # ~10 с, 15 803 файла в data/raw/…/strapi/uploads; падает, если остались пустые файлы
unzip -oq data/eval.zip -x '__MACOSX/*' -d data/eval
(cd data/eval && sha256sum -c checksums.sha256)
```

## Сборка каталога

```bash
.venv/bin/python -m winescan.catalog.build              # ~3 мин на 40 ядрах, из них ~2 мин — контактные листы
.venv/bin/python -m winescan.catalog.build --no-review  # ~1 мин, без контактных листов
```

Результат — `artifacts/catalog/`:

| Файл | Содержимое |
|---|---|
| `catalog.jsonl` | одна карточка вина на строку: поля CSV, атрибуты, файл эталона |
| `catalog.parquet` | та же таблица плоско, со служебными колонками (кандидаты, хеши, время загрузки) |
| `photo_matching.csv` | для каждого вина: статус привязки, выбранный файл, альтернативы, пояснение |
| `near_duplicate_images.csv` | группы вин с почти одинаковыми эталонами (pHash) |
| `uploads_index.csv`, `candidate_images.csv` | индекс всех файлов uploads и техописание кандидатов |
| `build_report.md` | сводка сборки |
| `review/*.jpg` | контактные листы: автоматические решения, ручные решения, группы дублей |

## Тесты

```bash
.venv/bin/python -m pytest
```

Тесты не требуют данных кейса: синтетические CSV, имена файлов и картинки.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `WINESCAN_DATA_DIR` | `data` | корень данных кейса |
| `WINESCAN_CATALOG_CSV` | `$WINESCAN_DATA_DIR/strapi_output0709.csv` | CSV-выгрузка каталога |
| `WINESCAN_UPLOADS_DIR` | `$WINESCAN_DATA_DIR/raw/prod-svoe-vino-strapi/prod-svoe-vino/strapi/uploads` | распакованные файлы Strapi |
| `WINESCAN_ARTIFACTS_DIR` | `artifacts` | куда писать результаты |
| `WINESCAN_PHOTO_OVERRIDES` | `configs/photo_overrides.csv` | ручные решения по фото |

Относительные значения по умолчанию считаются от корня репозитория.

## Ручные решения по фото

`configs/photo_overrides.csv`, колонки `slug,image_file,reason`. `image_file` — имя файла в
uploads; пустое значение означает «у вина нет подходящего эталона». Сборка падает, если slug
или файл не существуют. Сейчас 13 решений, каждое проверено глазами; причины записаны в файле.

## Ограничения

- Дампа базы Strapi в данных нет, связь «вино → файл» восстановлена по именам файлов и времени
  загрузки (см. docs/DATA.md, раздел 4).
- 11 файлов-эталонов в CSV привязаны сразу к двум винам; часть таких пар — ошибки контента.
  По изображению такие вина не различить.
- 2 эталона — атмосферные фото без бутылки; около 25 вин в bag-in-box, тетрапаке и банках.
- Атрибуты вина берутся эвристически из названия: год найден у 5,5% вин, сладость — у 82%.
- Публичный тестовый набор — 3 фото; 2 из 3 вин по названию в каталоге не найдены.
- Git-репозиторий пока не инициализирован.
